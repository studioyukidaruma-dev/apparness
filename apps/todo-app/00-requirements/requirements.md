## 概要 (Summary)

個人が日々のタスクを管理するためのシンプルなTODO管理Webアプリケーション。
タスクの追加・編集・削除・完了管理を行い、期限・優先度・カテゴリによる整理を可能にする。
サーバーやアカウント登録を必要とせず、ブラウザ単体で完結する。

## 目的 (Goals)

- タスクをすばやく追加・編集・削除できる
- タスクの完了状態を管理できる
- 期限・優先度・カテゴリでタスクを整理できる
- サーバーやアカウント登録なしに、ブラウザだけで使い始められる

## やらないこと (Non-Goals)

- 複数ユーザーでのタスク共有・アサイン機能は提供しない
- リアルタイム共同編集は提供しない
- モバイルネイティブアプリの提供は行わない（レスポンシブWebで対応）
- プッシュ通知・リマインダー機能は初期スコープ外
- 他サービス（カレンダー等）との連携は初期スコープ外

## 想定ユーザー (Target Users)

- 個人で日々のタスクを管理したい単一ユーザー（ログイン機能なし、ブラウザ単位でデータを保持）

## 機能要件 (Functional Requirements)

| ID | タイトル | 優先度 | 説明 |
|---|---|---|---|
| FR-1 | タスクの追加 | MUST | ユーザーはタイトルを入力して新しいタスクを追加できる |
| FR-2 | タスク一覧の表示 | MUST | 登録済みのタスクを一覧表示する |
| FR-3 | 完了状態の切り替え | MUST | タスクを完了/未完了の間で切り替えられる |
| FR-4 | タスクの編集 | MUST | 既存タスクのタイトル・期限・優先度・カテゴリを編集できる |
| FR-5 | タスクの削除 | MUST | 不要になったタスクを削除できる |
| FR-6 | 期限の設定 | MUST | タスクに期限日を設定・表示できる |
| FR-7 | 優先度の設定 | MUST | タスクに優先度（高・中・低）を設定・表示できる |
| FR-8 | カテゴリ/タグ付け | MUST | タスクにカテゴリまたはタグを付与できる |
| FR-9 | 絞り込み・並び替え | SHOULD | 完了状態・期限・優先度でタスクを絞り込み・並び替えできる |
| FR-10 | データの永続化 | MUST | 登録したタスクはブラウザを閉じたり再読み込みしても保持される |

各要件の受け入れ基準は `requirements.machine.yaml` の `acceptance_criteria` を参照。

## 非機能要件 (Non-Functional Requirements)

- [アーキテクチャ] クライアントサイドのみで動作し、サーバーやアカウント登録は不要とする
- [互換性] モダンブラウザ（Chrome / Edge / Firefox / Safari の最新版）で動作すること
- [ユーザビリティ] レスポンシブデザインとし、PCとスマートフォンの両方から利用できること
- [性能] 初回表示は概ね3秒以内を目安とする

## 制約 (Constraints)

- データはブラウザのローカルストレージ（端末・ブラウザ単位）に保存し、v1ではサーバー・DBを持たない
- 認証・アカウント機能は持たない
- 端末・ブラウザをまたいだデータ同期は行わない

- なし（すべて解消済み）
